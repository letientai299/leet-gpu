## Reading notes

- [x] 7.1 Background
  - 1D convolution: a function takes an **input array** of `n` elements and a
    **filter array** of `2r+1`, and returns an **output array**
  - Boundary handling:
    - assign default value for _ghost cells_ (missing elements).
    - Not all applications use 0 as value of ghost cells.
    - Boundary affect efficiency of tiling.

- [x] 7.2 Parallel convolution: a basic algorithm
  - Common naming in this chapter:
    - Input: `N`
    - Filter: `F`
    - Output: `P`
    - Radius of the square filter: `r`
    - `width` and `height` of the input array `N`.
  - [`conv.basic`][conv-basic]
    - Control divergence due to bound check.
    - High GMEM traffic
    - 8B, 2 OP, 0.25 OP/B

- [x] 7.3 Constant memory and caching
  - Properties of `F` that make it fits for constant mem and caching:
    - radius is often small ($\le 7$)
    - its content isn't never change
    - all threads access `F` in the same orders.
  - Constant mem limit: **64kb**, live in DRAM, but its requirements enable
    strong caching support.
  - [`conv.constant`][conv-constant]

- [x] 7.4 Tiled convolution with halo cells
  - The **input tile** is larger than **output tile**, need `+2r` for each
    dimension. Thus, 2 threading strategies:
    - Thread block matches input tile, reduce occupancy when compute output.
    - Thread block matches output tile, more complex input loading.
  - Halo cells: those extra cells in the input tile compare to the output tile.
  - [`conv.tiled`][conv-tiled]

- [x] 7.5 Tiled convolution using caches for halo cells
  - [`conv.cached`][conv-cached]

- [x] 7.6 Summary

### Ex 7.3

What do you think the following 1D convolution filters are doing?

- a. $[0\ 1\ 0]$

  **Answer**: it's an identify mask. The output is exactly same with the input.

- b. $[0\ 0\ 1]$

  **Answer**: shift element from right to left by 1, set the right most to 0.

- c. $[1\ 0\ 0]$

  **Answer**: shift element from left to right by 1, set the left most to 0.

- d. $[-\frac{1}{2}\ 0\ \frac{1}{2}]$

  **Answer**: each cell of the output contains the average different between its
  left and right neighbors.

- e. $[\frac{1}{3}\ \frac{1}{3}\ \frac{1}{3}]$

  **Answer**: A _blurring_ kernel where each output cell become the average of
  its and the 2 neighbors.

### Ex 7.4

Consider performing a 1D convolution on an array of size $N$ with a filter of
size $M$:

- a. How many ghost cells are there in total?

  **Answer**: $M-1$ ghost cells total.

- b. How many multiplications are performed if ghost cells are treated as
  multiplications (by $0$)?

  **Answer**: $N \cdot M$

- c. How many multiplications are performed if ghost cells are not treated as
  multiplications?

  **Answer**: $N \cdot M - 2\sum_{0}^r i = N \cdot M - r(r+1)$ where
  $r = \frac{M-1}{2}$

### Ex 7.5

Consider performing a 2D convolution on a square matrix of size $N \times N$
with a square filter of size $M \times M$:

a. How many ghost cells are there in total?

**Answer**: Let's use `r` in our math to simplify them. Number of ghost cells
are: $4r^2 + 4Nr = 4r(N+r)$

b. How many multiplications are performed if ghost cells are treated as
multiplications (by $0$)?

**Answer**: $N^2 M^2 = (NM)^2$

c. How many multiplications are performed if ghost cells are not treated as
multiplications?

**Answer:** Let's break it down. $r = \frac{M-1}{2}$, $M = 2r+1$. Output
$(i, j)$ multiplies only in-range taps, so the count is $R_i C_j$ with $R_i$
(resp. $C_j$) the 1D valid-tap count from Ex 7.4c.

Interior outputs, full $M \times M$ window inside $N$:

```math
(N-2r)^2 M^2
```

Four edge strips (not corners), $r \times (N-2r)$ cells each. Along the interior
axis the window is full ($M$). Along the border, output $k$ in
$\lbrace 0, \ldots, r-1 \rbrace$ has $k+r+1$ valid taps:

```math
\sum_{k=0}^{r-1}(k+r+1) = \frac{r(3r+1)}{2}
```

```math
4(N-2r)M \cdot \frac{r(3r+1)}{2} = 2(N-2r)M r(3r+1)
```

Four $r \times r$ corners. Each corner is the product of two independent 1D
border sums. At a corner output $(i, j)$, there are $R_i$ valid filter rows and
$C_j$ valid filter columns, so it performs $R_i C_j$ multiplications. For one
corner:

```math
\sum_{i=0}^{r-1}\sum_{j=0}^{r-1} R_i C_j
= \left(\sum_{i=0}^{r-1} R_i\right)
  \left(\sum_{j=0}^{r-1} C_j\right)
= \left(\frac{r(3r+1)}{2}\right)^2
```

The four corners have the same count by symmetry:

```math
4\left(\frac{r(3r+1)}{2}\right)^2 = r^2(3r+1)^2
```

Interior + edges + corners:

```math
\begin{array}{lll}
T &= \left[(N-2r)M + r(3r+1)\right]^2 \\
  &= \left[NM - r(r+1)\right]^2
\end{array}
```

Same as $(\sum_i R_i)(\sum_j C_j)$: each 1D factor is Ex 7.4c.

### Ex 7.6

Consider performing a 2D convolution on a rectangular matrix of size
$N_1 \times N_2$ with a rectangular mask of size $M_1 \times M_2$:

a. How many ghost cells are there in total?

**Answer**: Let's use $r_1 = \frac{M_1-1}{2}$ and $r_2 = \frac{M_2-1}{2}$. Count
of ghost cells are:

```math
G = 4r_1 r_2 + 2 N_1 r_2 + 2 N_2 r_1
```

b. How many multiplications are performed if ghost cells are treated as
multiplications (by $0$)?

**Answer**: $N_1 N_2 \cdot M_1 M_2$

c. How many multiplications are performed if ghost cells are not treated as
multiplications?

**Answer:** Let's define $r_1 = \frac{M_1-1}{2}$, $r_2 = \frac{M_2-1}{2}$,
$M_1 = 2r_1+1$, $M_2 = 2r_2+1$. Output $(i, j)$ multiplies only in-range taps,
so the count is $R_i C_j$ with $R_i$ (resp. $C_j$) the 1D valid-tap count from
Ex 7.4c along $N_1$ (resp. $N_2$).

Interior outputs, full $M_1 \times M_2$ window inside $N_1 \times N_2$:

```math
(N_1-2r_1)(N_2-2r_2) M_1 M_2
```

Two $N_2$-interior edge strips, $r_1 \times (N_2-2r_2)$ cells each. Along $N_2$
the window is full ($M_2$). Along $N_1$, output $k$ in
$\lbrace 0, \ldots, r_1-1 \rbrace$ has $k+r_1+1$ valid taps:

```math
\sum_{k=0}^{r_1-1}(k+r_1+1) = \frac{r_1(3r_1+1)}{2}
```

```math
2(N_2-2r_2)M_2 \cdot \frac{r_1(3r_1+1)}{2} = (N_2-2r_2)M_2 r_1(3r_1+1)
```

Two $N_1$-interior edge strips, $(N_1-2r_1) \times r_2$ cells each:

```math
2(N_1-2r_1)M_1 \cdot \frac{r_2(3r_2+1)}{2} = (N_1-2r_1)M_1 r_2(3r_2+1)
```

Four $r_1 \times r_2$ corners. Each corner is the product of two independent 1D
border sums:

```math
4 \cdot \frac{r_1(3r_1+1)}{2} \cdot \frac{r_2(3r_2+1)}{2}
= r_1(3r_1+1) r_2(3r_2+1)
```

Interior + edges + corners:

```math
\begin{array}{lll}
T &= \left[(N_1-2r_1)M_1 + r_1(3r_1+1)\right]
     \left[(N_2-2r_2)M_2 + r_2(3r_2+1)\right] \\
  &= \left[N_1 M_1 - r_1(r_1+1)\right]
     \left[N_2 M_2 - r_2(r_2+1)\right]
\end{array}
```

Same as $(\sum_i R_i)(\sum_j C_j)$: each 1D factor is Ex 7.4c.

See also [`./ch07.mult_count_3d.md`](./ch07.mult_count_3d.md)

### Ex 7.7

Consider performing a 2D tiled convolution with the kernel shown in Fig. 7.12 on
an array of size $N \times N$ with a filter of size $M \times M$ using an output
tile of size $T \times T$.

a. How many thread blocks are needed?

**Answer:** $\left\lceil \frac{N}{T} \right\rceil^2$ thread blocks.

b. How many threads are needed per block?

**Answer:** ${T+M-1}^2$

c. How much shared memory is needed per block?

**Answer:** $4 (T+M-1)^2$ bytes

d. Repeat the same questions if you were using the kernel in Fig. 7.15.

**Answer:**

- Number of thread blocks: $\left\lceil \frac{N}{T} \right\rceil^2$
- Number of thread per block: $T^2$
- Size of shared mem: $4*T^2$ bytes
