# 3D convolution multiplication count

This is my follow up on chapter 7 exercises, to see if the 3D convolution would
also result in similar formulate for the number of multiplications.

Given:

- An input of size $N_w \times N_h \times N_d$
- A filter of size $M_w \times M_h \times M_d$.

Let $r_w = \frac{M_w-1}{2}$, $r_h = \frac{M_h-1}{2}$, $r_d = \frac{M_d-1}{2}$,
so $M_w = 2r_w+1$, $M_h = 2r_h+1$, $M_d = 2r_d+1$.

a. How many ghost cells are there in total?

**Answer:** Padded volume minus the input:

```math
\begin{array}{lll}
G &= 2 N_h N_d r_w + 2 N_w N_d r_h + 2 N_w N_h r_d \\
  &+ 4 N_d r_w r_h + 4 N_h r_w r_d + 4 N_w r_h r_d \\
  &+ 8 r_w r_h r_d
\end{array}
```

b. How many multiplications are performed if ghost cells are treated as
multiplications (by $0$)?

**Answer:** $N_w N_h N_d \cdot M_w M_h M_d$

c. How many multiplications are performed if ghost cells are not treated as
multiplications?

**Answer:** Output $(i, j, k)$ multiplies only in-range taps, so the count is
$W_i H_j D_k$ with $W_i$, $H_j$, $D_k$ the 1D valid-tap counts from [Ex
7.4c][ex-74c] along $N_w$, $N_h$, $N_d$.

Interior outputs, full $M_w \times M_h \times M_d$ window inside the volume:

```math
(N_w-2r_w)(N_h-2r_h)(N_d-2r_d) M_w M_h M_d
```

Two faces with halo in width, $r_w \times (N_h-2r_h) \times (N_d-2r_d)$ cells
each. Along height and depth the window is full ($M_h$, $M_d$). Along width,
output $t$ in $\lbrace 0, \ldots, r_w-1 \rbrace$ has $t+r_w+1$ valid taps:

```math
\sum_{t=0}^{r_w-1}(t+r_w+1) = \frac{r_w(3r_w+1)}{2}
```

```math
2(N_h-2r_h)(N_d-2r_d) M_h M_d \cdot \frac{r_w(3r_w+1)}{2}
= (N_h-2r_h)(N_d-2r_d) M_h M_d r_w(3r_w+1)
```

Two faces with halo in height:

```math
(N_w-2r_w)(N_d-2r_d) M_w M_d r_h(3r_h+1)
```

Two faces with halo in depth:

```math
(N_w-2r_w)(N_h-2r_h) M_w M_h r_d(3r_d+1)
```

Four edges along width (halo in height and depth),
$(N_w-2r_w) \times r_h \times r_d$ cells each. Each edge is the product of one
interior 1D factor and two independent 1D border sums:

```math
4(N_w-2r_w)M_w \cdot \frac{r_h(3r_h+1)}{2} \cdot \frac{r_d(3r_d+1)}{2}
= (N_w-2r_w)M_w r_h(3r_h+1) r_d(3r_d+1)
```

Four edges along height:

```math
(N_h-2r_h)M_h r_w(3r_w+1) r_d(3r_d+1)
```

Four edges along depth:

```math
(N_d-2r_d)M_d r_w(3r_w+1) r_h(3r_h+1)
```

Eight $r_w \times r_h \times r_d$ corners. Each corner is the product of three
independent 1D border sums:

```math
8 \cdot \frac{r_w(3r_w+1)}{2} \cdot \frac{r_h(3r_h+1)}{2}
  \cdot \frac{r_d(3r_d+1)}{2}
= r_w(3r_w+1) r_h(3r_h+1) r_d(3r_d+1)
```

Interior + faces + edges + corners:

```math
\begin{array}{lll}
T &= \left[(N_w-2r_w)M_w + r_w(3r_w+1)\right]
     \left[(N_h-2r_h)M_h + r_h(3r_h+1)\right] \\
  &\quad \left[(N_d-2r_d)M_d + r_d(3r_d+1)\right] \\
  &= \left[N_w M_w - r_w(r_w+1)\right]
     \left[N_h M_h - r_h(r_h+1)\right] \\
  &\quad \left[N_d M_d - r_d(r_d+1)\right]
\end{array}
```

Same as $(\sum_i W_i)(\sum_j H_j)(\sum_k D_k)$: each 1D factor is [Ex
7.4c][ex-74c].
